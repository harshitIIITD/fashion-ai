# Fashion AI CLI - Demo

This is a demo workspace to showcase Fashion AI CLI capabilities.

## Available Fashion Tools

1. **Trend Analysis** (`trend_analysis`)
   - Analyze seasonal fashion trends
   - Market insights and recommendations
   - Target audience analysis

2. **Color Palette Generator** (`color_palette`)
   - Create harmonious color schemes
   - Based on inspiration sources
   - Seasonal appropriateness

3. **Size Conversion** (`size_conversion`)
   - Convert sizes between regions
   - Support for multiple categories
   - Comprehensive size charts

## Example Prompts

- "Analyze spring 2024 trends for women's apparel"
- "Create a sunset-inspired color palette for summer collection"
- "Convert US size 8 dress to EU sizing"
- "What are the trending colors for fall accessories?"
